# React Challenge 2 — User Management Dashboard

## Problem Description

Build a React application that fetches user data from an external API and provides a small user-management interface.

The goal of this challenge is to practice combining React fundamentals into a single working application rather than implementing isolated concepts.

## Requirements

The application must:

1. Fetch users from an external API.
2. Display the users in a table.
3. Display:
   - Name
   - Username
   - Email
4. Provide a search input.
5. Allow users to be searched by:
   - Name
   - Username
   - Email
6. Provide a **View Details** button for each user.
7. Display additional information for the selected user:
   - Name
   - Username
   - Email
   - Company
   - Website
8. Provide a **Delete** button for each user.
9. Remove the selected user from the displayed user list when deleted.
10. Display:
    - Total number of users
    - Number of currently visible users
11. Display appropriate UI for the selected user/details section.
